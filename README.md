# School Football ⚽

Modern Persian RTL school football management platform built with Next.js.

## MVP
- Teacher/admin dashboard
- Classes and teams
- Match scheduling and results
- Tournament management
- League standings
- Player management foundation

## Roadmap
1. Supabase Auth + PostgreSQL
2. Teacher/admin and student roles
3. Persistent schools, classes, teams, players and tournaments
4. RLS policies and audit logs
5. Live match updates and player statistics
6. Mobile/PWA polish
